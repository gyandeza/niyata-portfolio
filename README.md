# NIYATA — Professional Portfolio

Clean-history public source for the NIYATA professional portfolio.

**Positioning:** Industrial Engineering × Supply Chain × Digital Transformation × Project Management × Applied AI.

## Development

- `npm install`
- `npm run dev`
- `npm run build`
- `node tests/flow-model-fixtures.mjs`
- `node tests/premerge-smoke.mjs`
- `node tests/staging-artifact-guard.mjs` (after build)

The website is a multi-page Vite/React application. Output: `dist/`.

## Deployment status

Source-only initial migration. Production cutover and public domain deployment are **not approved**. Protected preview and mobile QA are required first.

## Disclosure boundary

Public-facing prototypes are illustrative and not validated operational planning or safety tools. Employer-sensitive operational data and legacy private-finance content are excluded.
